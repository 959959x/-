# 数学论文写作与证明审查
本目录为可移植导出版。默认只完成当前请求；安装或调用不会自动启动训练、持续选文或修改技能。训练及技能更新须有相应明确授权。来源摘要不能替代原文与证明核查；不得编造阅读经历或验证结果。


## 兼容入口与两套关联技能

本入口按当前任务分流。涉及推理、数学审查和证明重建时使用 [$mathematical-reasoning](../mathematical-reasoning/SKILL.md)；涉及已核数学的独立组织、写作审查和跨文比较时使用 [$mathematical-writing](../mathematical-writing/SKILL.md)。二者分工但不割裂：先完成数学审查修正，再审写作，最后才开放原文比较。

仅在用户明确要求论文训练时，读取同包的[训练契约](../mathematical-writing/references/training-contract.md)，遵守其中阶段门槛、七项报告和证据分级。文体观察不自动成为 Level 3 规则；限定单元不能替代整篇验证。

## 确认任务边界

- 默认用中文交流；按用户要求确定论文语言及输出格式。尊重指定环境；用户指定云端时，留在云端，不调用本地电脑。
- 先识别当前模式：研究推导、证明审查、论文组织、文字润色、论文学习或数学建模。信息足够时直接开展；只询问影响结论的缺失条件。
- 读取用户实际提供的方程、文稿及最近要求。建立当前任务的方程版本、空间维数、区域及边界、初始条件、参数范围、目标结论和允许修改范围。切勿混合相似方程或移植旧项目结论。
- 遵守本次范围。不要默认增添新定理、加强结论或补写用户未要求的研究方向。过去单个项目的排除项不构成本技能的永久禁令。
- 将“用户给定但待审”“文献已证且适用条件已核对”“本次已完成推导”“条件性结论”“尚未证明”分开。不要把审稿式检查或语言流畅度等同于数学正确性。

## 先确定语言路线

- 中文原创写作：用中文直接组织数学论证与正文，读取 [语言路线](references/language-routes.md) 的中文部分。不能将中文输入默认为翻译或英文输出。
- 英文原创写作：按英文数学论文行文直接起草，读取同文件英文部分；不先生成僵硬的中文逐句译稿。
- 中文润色与英文润色：分别在原语言内部处理衔接、术语和句法，保留数学内容与强度；除非明确要求，不变更语言。
- 翻译：只有用户明确要求才进入翻译模式，确认源语言与目标语言；禁止把润色自动扩展成翻译。
- 语言未明时，根据用户指定的输出与当前文稿判断；存在实质歧义才问。正文语言与解释语言可以不同，分别遵守要求。

## 按模式处理

- **研究推导**：说明所求命题及策略，展开可检查的计算和推理；遇到缺口，给出确切位置、缺少的估计/条件及可行下一步。不得用“标准论证”遮盖关键步骤。
- **证明审查**：读 [证明审查清单](references/proof-audit.md)。先检查结论成立的必要条件，再逐条审查依赖与估计；区分反例、缺失假设、证明缺口和表达问题，避免无证宣称某个定理错误或正确。
- **论文组织/全文重写**：先读 [全文组织与编辑验收](references/manuscript-editing.md)，再按需读 [PDE论文写作风格](references/pde-writing-style.md)。用论证主题和读者依赖决定章节、定理与证明位置、正文附录分工；不能把任务清单换成目录，或靠操作式过渡冒充数学解释。数学基线与风格参考分开，不把新修订稿视为已被用户认可。
- **文字润色**：保留原数学意义、量词、参数区间、范数、指标及结论强度。只改授权范围；发现数学疑点单列说明，不悄悄修正或伪装成原文已证结果。
- **论文学习**：沿着定义—前置工具—关键估计—定理证明解释；以用户熟悉 Sobolev 空间和 Fourier/Littlewood–Paley 基础为起点，遇到更深工具先讲清所需版本、适用条件和用途。默认不用练习或额外例题；该偏好仅限学习模式，不限制证明中的反例或必要示例。
- **从文献训练写作方法**：必须读 [基于证明理解的写作学习](references/proof-grounded-writing.md)，实际完成“读懂并重建证明 → 隔离原文表达独立写作 → 与原稿对照诊断 → 改变条件的迁移检验”。只浏览文字、摘取连接词或增加流程说明，均不算训练完成。根据能力明确范围；完整读过全文不等于独立验证了全部定理，单个完整论证单元不等于整篇写作已通过。普通润色和翻译仍按各自授权范围处理，不强制扩成研究。
- **数学建模**：区分建模假设、数学推论、统计拟合与数值观察；报告量纲、标定数据、可识别性、边界条件、误差来源、敏感性和验证范围。不要把模拟图像当作定理证据。

## 执行核心流程

1. **锁定对象与记号**：列出工作所需的定义、假设、参数与函数空间。统一同一符号含义；注明齐次/非齐次空间、时间和空间范数顺序、弱/强意义、常数允许依赖的量。不要过度创建表格；短任务在说明中完成。
2. **构建证明依赖**：从目标定理向前追踪引理、外部定理和关键估计，检查无循环论证、无隐含强化、无用最终结论证明前提。临时假设须在闭合步骤中解除。
   从参考论文提炼写作规则时，先形成去除原文措辞、目录和编号的数学事实卡；未核关键依赖不得伪装成卡片中的已知事实。学习记录与论文成稿分开，规则须能追溯到实际论证和对照证据。
3. **逐步推导与核对**：核对量词、端点、指数及缩放、积分分部和边界项、交换极限的条件、紧性和收敛类型；不要以形式计算替代合法化。
4. **完成论证闭合**：分别说明存在、唯一、正则性、延拓、长期行为等本次要求的结论。只声称已经覆盖的部分。附加性质是否需要证明由本次目标决定。
5. **核验文献**：通过原论文、作者公开版本或出版商原文核对标题、作者、年份、定理/页码、假设和适用性；优先一手来源。实际无法读取时明确未核验，不编造文献、DOI、定理号或引用支持。检索结果和摘要不足以确认关键引理。引用已验证网页链接；查重概念不等于原创性证明。
6. **写成连贯正文**：解释具体数学障碍及机制，按读者依赖选择集中陈述或分节证明并保留准确映射；仅在需要时给一次短路线。短定义自然嵌入段落，关键公式清晰展示，避免反复“先、再、最后”的操作口吻。段落间用数学逻辑衔接，避免正文成为检查清单。保留审查记录与论文正文的区别；读 [PDE论文写作风格](references/pde-writing-style.md) 后取其可推广原则，不复制来源的特色表述。
7. **按交付要求验证**：整稿必须按 [全文组织与编辑验收](references/manuscript-editing.md) 分别完成技术/编译、全文编辑、数学保持检查，不能用短样稿或编译成功替代。数学保持不等于对原命题的完整数学审查。若需文件，使用相应文档/LaTeX/PDF工具并实际检查渲染；报告各层完成范围与遗留问题。

## 按需加载领域与文献样本参考

- 默认优先流体动力学方向的参考与证明组织，重点是能量估计、适定性及长期行为；结合当前方程选择相对能量、磁流体、黏性流体或衰减范例，不能混同不同模型。其他椭圆、非局部和色散范例仅在当前论证确实用到相应方法时加载，不作为等权默认模板。用户当前明确指定的方向始终优先。

- 中文数学期刊的独立行文依据：读 [中文PDE外部范例](references/chinese-pde-writing-style.md)，与其他中文样本对照，不把单篇习惯当成统一规范。
- 椭圆、非局部正则性与紧性改进：读 [椭圆写作范例](references/elliptic-writing-style.md)。
- 色散估计、双曲临界问题与紧致性—刚性：读 [色散双曲写作范例](references/dispersive-writing-style.md)。
- 非局部抛物、正则化或迭代论证：读 [抛物写作范例](references/parabolic-writing-style.md)。
- 所列文献样本：读 [中英文定向风格参考](references/literature-style-samples.md)，先识别语言与文体，再提取有页码依据的习惯；只把多篇支持的重复做法称为样本倾向。区分用户明确偏好、单篇写法、普遍规范与未核实推测，不猜作者师生身份。
- 作者身份或声望不保证任一数学步骤正确。文献样本风格与数学清晰性冲突时说明冲突，不机械仿写。
- 既有范例中的结构与语言观察只支持相应观察；未经证明重建、独立写作和对照的条目，不能标为经验证的证明驱动写作规则。采用新规则前区分数学依赖必需、具体解类所需与可替换的编辑选择。
- 只保存抽象规则与必要来源，不将用户论文全文打包进可移植技能；需要精准模仿或核查时重新读用户授权原文。

## 输出与诚实边界

- 简短审查先给阻塞性问题，再给修正建议；长任务提供范围内的完整正文/证明及独立缺口清单。明确已验证范围与仍缺证据处，不泛称“完全严谨”。
- 需要展示图表时保留数据来源、代码、参数、随机种子（若随机）和环境信息，实际运行后检查；中文图表选择环境中实际存在且支持中文的字体，验证文字显示。图例和坐标含变量、量纲及必要说明，禁止伪造实验数据。
- 不强制产出与请求无关的图、论文文件、练习、外部上传或新研究。先完成用户要求的数学任务。
