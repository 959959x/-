# 写作候选

候选等级为 Level 2 / candidate，非核心、非 validated、非 strong，不作自动定理或强制模板。

这是使用版。来源与定位见[证据来源](evidence-sources.md)；摘要不替代原始证明。等级及适用/不适用边界须保留，缺少材料不允许推定验证成功。

## KM86-W03 同一对象与范围的收束（Level2 Candidate）

Rule: 多构造、多维数或多端点汇合且读者需要追踪兼容关系时，在实际闭合处明确同一解/代表以及最终时间、参数范围；可用前置统一约定、证明尾句或小节，不固定结论段格式。
Reason: 分支输出分别正确仍可能被读成换了解或换了参数；适当收束使已经证明的兼容关系可检查，但文字本身不提供数学同一性。
Use when: 构造选择、逐时代表及多个输出分别负有责任，而最终定理要求它们属于同一对象；需要向读者显示如何返回原固定参数。
Avoid when: 同一性尚未证明；前置约定与回引已足够清楚；不为形式完整重复摘要或强制Conclusion，不让结语代替证明。
Good pattern: KM的统一传界/共同近似包络把四输出送给同一构造解；固定n,u,t0后以同一端点包络同时关闭全部q。
Bad pattern: 逐目标另选解或起点而未证明兼容，却只写“主定理得证”；把固定起点结果扩大成移动起点统一性；机械给所有短证明另加总结节。
Evidence: Kajikiya–Miyakawa 1986 pp.138–139、144 与 Rigelo 等 2016 p.504 (1.9)、p.508 (3.6) 后的回收，涉及同一对象、参数范围及结论兼容。相关来源只支持检查这些数学责任，不能推断两原刊都采用固定结论段。Brezis–Gallouët 1980 与 Fujita 1966 p.118 的轻量回收，适用于前置约定已固定单一解、无需新增多构造兼容证明的场景。前置约定与准确回引足够时，不强制结语段或 Conclusion。

Confidence: Level2/candidate，范围受限，非核心强制规则；依据KM/Rigelo两独立来源的兼容责任和条件性收束作用。缺少本候选独有额外收益的证据，保持L2，不升L3/strong。一般部分与MW-O001/O003关联；仍须核当前用途及已有前置约定是否充分。
