# 范围受限的已验证写作规则

核心等级为 Level 3 / validated，范围受限、非 strong；不能替代当前证明，不保证普遍最优或成稿正确。

这是使用版。来源与定位见[证据来源](evidence-sources.md)；摘要不替代原始证明。等级及适用/不适用边界须保留，缺少材料不允许推定验证成功。

## MW-O001 以实际依赖和写作目的决定信息顺序

Rule: 先识别本文要建立的结果职责、关键估计的下游用途与读者需要，再安排定义、引理、主结果和证明。让调用关系可定位；可明确前引并延后证明，不把所有合法顺序压成固定目录。
Reason: 读者需要区分通用结构与应用、必要输入与普通准备，才能理解新对象为何出现；证明依赖限制调用，但不唯一决定研究叙事的顺序。
Use when: 多阶段PDE证明或实现条件明确的抽象演化或双线性尺度估计、工具与应用分层、弱形式与强解比较、关键中间量有多个后续用途；或研究论文与完整学习稿的终点不同。
Avoid when: 短的一步证明、并列独立结果、背景定位自有叙事需求；若核心前置需要大量未定义接口，应先补必要概念而不是机械提前。不要删掉为独立查阅服务的完整条件。
Good pattern: 明确一个加强估计将关闭哪个难点，再证明它；通用比较结构作为研究贡献时先建立该接口，完整唯一性教程也可先给终点与合法性。
Bad pattern: 只照搬来源目录；连续摆出定理而不说明关系；或把“关键机制突出”误写为所有核心计算必须最先出现。
Evidence: Liu–Yang 2017 pp.8–14 与 2020 是相关来源；两文只计一个相关作者/模型家族。围绕这些来源的相关问题，使用者须分别核对一致估计、构造与时间迹的依赖责任；所列出处不表示原文已给出全部时间迹细节。Feireisl–Jin–Novotný arXiv:1111.3082v1 pp.5–6、8、12，区分相对结构、扩测试与唯一性应用。Koch–Tataru 2007-12-26 作者版 p.7 Step 3 / (15)、p.9 Remark 3.3，涉及核心热势、尺度核验与替代路线。DMS 2010 v1 / 2012 作者稿 pp.5–7、Keel–Tao 1998 pp.960–968 展示工具与待解障碍的不同组织方式。机制集中和独立查阅定量细节是不同读者需要；工具可前置，也可在明确缺口后引入，实际条件仍须完整兑现。来源例子不产生固定最佳目录，限定端点与单元不覆盖全篇或所有指数。

Confidence: validated，Level3；依据多独立作者/问题及可解释的实际调用关系。只对上述条件式原则给支持，不保证任意排序或任意方案整体更好；遇新场景冲突需收窄、降级或拆分。

## MW-O002 按实际核查任务分配解释密度

Rule: 在决定性估计、合法性跨越和结论闭合处给足可检查的数学理由；对条件已明且可直接恢复的常规计算可压缩或复用。以读者和证明责任决定详略，不以字数、公式数或页数代替质量。比较两条正确路线时，列出新增中间结论、升级与重复认同的数学/解释用途，准确复用已经得到的接口；没有直接后用不自动等于冗余。
Reason: 均匀扩写会掩盖主障碍，均匀压缩会隐藏真实接口；一个正确的短定量界有时比多句“标准论证”更能完成核查。
Use when: 证明含少数决定步骤与一批常规计算，且读者基线、实际调用条件及完整性目标明确。
Avoid when: 所谓标准工具的条件尚未核验，或受众确需基础推导；来源简写与学习稿补足的责任不同时，不能将额外数学证明算作纯文风胜出。多用中间结果本身不等于冗余。
Good pattern: 能量中共享消去的计算紧凑相邻；需要从L¹收敛识别非局部算子时写出直接接上测试配对的短界；真空体积估计取得L²控制后复用已证Hölder模板。
Bad pattern: 将每个Young不等式各立引理；用“显然”删去唯一解释抵消的公式；因为另稿更短而删掉初始迹或算子认同。
Evidence: Liu–Yang 2017 p.11 (3.11)–(3.13) 的相邻能量计算与 2020 (3.10)–(3.16)、(3.30)–(3.38) 的工具路线，分别体现紧凑计算和条件使用。Feireisl–Jin–Novotný v1 pp.5–6、8、12 Remark 4.2 区分短组合、比较类合法性和闭合条件，不能为简洁删除时间迹或 a.e. 收束。Koch–Tataru 作者版 p.8 长计算链、p.9 热势引用，DMS 的图域与生成性条件，Keel–Tao pp.964、966–967 的尺度与序列收束，均须按实际核查目标决定解释密度。额外数学补证不是纯文风收益；中间结论即使无直接后用，也可能承担结构说明。字数和页数不能替代具体依赖判断。

Confidence: validated，Level3；依据多作者/问题中按责任分配解释的数学理由，只支持条件化的局部取舍。未证明任意读者获益或任意方案整体优越，不标strong。

## MW-O003 按数学语言的功能而非措辞相似性比较

Rule: 在来源比较或结构修订时，先把语句落实到提出问题、指出障碍、解释估计、说明条件、连接任务或收束结论的具体作用，再决定保留、压缩或移位；不要把记住句式或同义改写当成可迁移成果。
Reason: 相同连接词可以承担不同任务；看似重复的限定可能保护不同接口。把作用接到实际公式/假设/结果，才能说明一句话为何必要或为何冗余，而不是凭个人口吻评价。
Use when: 数学机制已核，来源比较门槛已开放，或对已有正确稿作结构性编辑；可精确指出文字服务的数学责任与受众目标。
Avoid when: 严格引文、忠实翻译或术语规范要求保留表达；尚有数学疑点时先审数学。功能分类不是每段模板，不能凭“作用清楚”容忍错误断言，也不要求短的一步证明配齐所有功能句。
Good pattern: 在产生待控项后说明还缺哪种界，再引入工具；把初值范数与逐时代表分别由什么条件保证说清；明确一处新增机制导语帮助识别哪种非线性关系，而不只说它更长。
Bad pattern: 统计hence/therefore或以同义词替换冒充学习；删掉所有重复出现的条件声明；把b^k的“线性代价”误述当作可随意保留的文风。
Evidence: Feireisl–Jin–Novotný arXiv v1 p.9 的余项吸收、p.12 的条件说明；Koch–Tataru 2007-12-26 作者版 p.7 (15) 前目标切换与 p.8 计算链说明；DMS 2010 v1 / 2012 作者稿 pp.5–7 的剩余任务；Keel–Tao 1998 pp.960、964–965 的路线、失败诊断与工具必要性，各有具体语言功能。Caffarelli–Vasseur 正式版 pp.1906–1907 (5) 说明非线性控制目标。摘要、导语与结语的量、量词和范围也须核数学，不因正文公式正确便自动正确。中文组织与英文来源比较不能认证英语成稿或中文原刊文体；额外数学补证不算纯表达收益。以上是功能定位的来源，不是句法模板或自动防错证明。

Confidence: validated，Level3；依据跨独立作者/问题中可定位的语言功能及具体组织作用。只支持带条件的比较判断，非句法模板、原创机制或整体优胜保证；无人类理解实验/统计因果证据，不标strong，遇反例可缩边界或降级。
