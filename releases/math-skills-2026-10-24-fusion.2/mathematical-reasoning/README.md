融合版本 **2026.10.24-fusion.2**，接入公开 R37（源 v37，2026-10-14；公开整理 2026-10-23）。这不是 R38，也不是新一轮训练成果。

从 [SKILL.md](SKILL.md) 开始；按当前问题读取[数学审查范围](references/audit-domains.md)。本 skill 支持研究推导、理解重建与证明审查；纯写作表达交给相邻的 [mathematical-writing](../mathematical-writing/SKILL.md)。明确报告数学变化和未闭合责任，不以润色为由静默改变假设、结论或证明。

[规则索引](references/validated-rules.md)包含 5 张范围受限的已验证检查卡，按稳定 ID 分文件；操作卡与历史 Evidence 分开，避免日常任务加载全部训练历史。[候选库](references/rule-candidates.md)仅有 HEAT-FK-M01 与 EULER-CET-DR-M01 两张活动 Level 2 卡；迁移条目只是历史指针。

`source_status` 保留来源报告的证据等级和 Confidence；`integration_status` 说明本次整合。来源的 supporting drafts、完整推导和审查记录未公开，本次未重新核验这些原论文，不构成公开可复现的 benchmark，也没有增加正确率、阅读效果或普遍适用性结论。SION-M03 保留两种合法实施路线，不强制系数域优先。

普通任务、限定文献学习与正式规则训练分别按请求处理；正式训练才采用[训练契约](references/training-contract.md)。安装、阅读或使用本技能不自动训练、持续选文或修改技能。已有明确授权在其范围内有效。

来源缩写可从[原有证据索引](references/evidence-sources.md)与写作 skill 的[选定公共书目](../mathematical-writing/references/bibliography.md)互补识别；后者不是完整训练语料。没有核明的条目保持未核，不补造题名或 DOI。

本版保留已有宿主配置与图标。上游文档的 [MIT 许可证](provenance/upstream-2026-10-23/LICENSE)与[原始许可范围](provenance/upstream-2026-10-23/LICENSE_SCOPE.md)随包保留；它们不自动为此前本地或其他来源材料重新授权。
