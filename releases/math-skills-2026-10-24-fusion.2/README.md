# 数学技能融合版 2026.10.24-fusion.2

本版把 [W35 / R37 公开包](https://github.com/959959x/-/tree/eb6f8130f67d2fb8c4d4d552985144d4412edde1/releases/math-skills-2026-10-23)的有效增量融合进 2026.10.10-fusion.1 本地版本，保留 Nature 研究定位与期刊适配模块，以及可覆盖的使用偏好。三个技能仍各司其职：

| 技能 | 用途 |
|---|---|
| [mathematical-writing](mathematical-writing/SKILL.md) | 原语言写作、润色、论证组织、指定期刊适配 |
| [mathematical-reasoning](mathematical-reasoning/SKILL.md) | 数学推导、证明重建、条件和闭合审查 |
| [math-paper-workflow](math-paper-workflow/SKILL.md) | 识别并组织研究、审查、写作、学习等任务 |

## 本版变化

- 写作规则 MW-O002 补入“收敛完成”与“极大性或定量峰值保留”的解释责任区分；MW-O001、MW-O003 保留原有适用边界。
- 推理新增范围受限的 SION-M03；MR-O001–004 保留操作内容。规则正文与较长来源证据分开，按问题读取。
- 区分普通编辑、限定学习与正式规则训练；普通写作可使用授权材料，隔离训练阶段才关闭来源。
- 接入公开书目、证据说明和参考选取；保留旧书目及可选风格样本，保留自动调用设置与图标。
- 保留上一版 Nature 融合模块，不将它们升级成经过训练验证的规则。

## 使用与安装

选择相应 SKILL.md，并只读取当前任务需要的参考。三个目录应作为同一套技能安装，跨技能链接依赖同级目录。覆盖安装前备份已有同名目录；本次用户本机安装的备份和实际验证记录另行交付。技能调用不会自动授权持续训练或外部上传。

本包保留原作者的本地使用偏好；当前任务和用户要求优先，其他使用者可按自身情况调整偏好档案。对用户授权的私人稿件可以进行本任务处理；公开技能仅保存必要的可分享规则与来源摘要。
