# math-paper-workflow · 2026.10.24-fusion.2

数学论文的 AI 辅助阅读、组织、编辑与范围限定审查。重点是让数学写作清楚可读，同时保持原有假设、结论和证明逻辑；不提供证明认证。

AI-assisted reading, organization, editing, and scoped review of mathematics papers. The aim is readable mathematical writing without silently changing assumptions, results, or proof logic, not proof certification.

## 用法 / Usage

从 [SKILL.md](SKILL.md) 开始。说明任务类型、材料、语言、数学基线和允许修改范围；按需要选择参考文件。将本目录与 [mathematical-reasoning](../mathematical-reasoning/SKILL.md) 和 [mathematical-writing](../mathematical-writing/SKILL.md) 并列放置以保留相对链接。

Start with [SKILL.md](SKILL.md). Specify the task, materials, language, mathematical baseline, and permitted changes. Keep this folder beside [mathematical-reasoning](../mathematical-reasoning/SKILL.md) and [mathematical-writing](../mathematical-writing/SKILL.md) for the relative links to work.

示例：请用本工作流润色这段中文证明，保持假设、量词、公式与结论不变；数学疑点单列，不自行修正。

Example: Use this workflow to improve the organization of this proof in English. Preserve its assumptions, quantifiers, formulas, conclusions, and proof logic; report mathematical concerns separately.
