# 数学建模结果审查与复现计划

现有材料只能支持“作者报告了8个标定观测点上的拟合误差”，不能支持“模型对未来样本普遍准确”。由于未提供观测数据和计算过程，RMSE=0.1本轮也无法核验。

## 审查意见

| 位置 | 问题、理由与影响 |
|---|---|
| 模型及参数 | 指数必须无量纲，故应写 (a=2\,\mathrm{mg/L})、(b=0.3\,\mathrm{h}^{-1})，RMSE单位为mg/L。还须交代时间零点、观测时间范围及适用条件。若用于浓度衰减，应说明正初始浓度、恒定衰减率等假设；由模型本身可得 (y(0)=a)，不能据此确认物理机制。 |
| RMSE与预测结论 | 同一批8点同时用于选参数和评价，只给出样本内拟合表现；若还用它们选择模型，选择过程也需披露。应删除“未来样本普遍准确”，暂改为“在用于参数标定的8个观测点上，报告的样本内RMSE为0.1 mg/L；未来样本预测能力尚待独立验证”。 |
| 随机模拟附图 | 模拟只显示给定生成机制下的数值结果，不能充当真实观测、独立验证或普遍准确性的证据。缺少输入及生成记录，无法确认能复现原图；后续重新模拟须明确标为新结果。 |
| 参数可识别性 | 不能将“未分析”直接判为“不可识别”。在正浓度、无噪声且至少两个不同时间点的理想情形，(b=[\log y(t_1)-\log y(t_2)]/(t_2-t_1))，再由 (a=y(t_1)e^{bt_1}) 唯一确定参数。但8个含噪观测的实际可识别性取决于时间覆盖、噪声及参数相关性，目前未知。 |
| 误差与不确定性 | 单个RMSE无法分解测量误差、参数估计不确定性、模型结构偏差和模拟误差，也不提供预测区间。0.1是否足够小须结合浓度尺度、测量精度和事先规定的应用容差判断。 |
| 中文方框 | 当前图中文字不可读。需要核实生成环境实际安装的中文字体，并检查导出文件；仅在代码中指定字体名称不足以证明修复。 |

## 需要补齐的复现与验证计划

1. **恢复并冻结原始材料。** 收集8点的原始时间、浓度、单位、来源、测量方法、重复测量及缺失/异常处理记录；保存未经改写的数据和处理后数据。分别归档观测与模拟输入。能找回的原代码、模拟参数、随机种子及环境据实保存；无法恢复的内容标为缺失，不追填虚构记录。
2. **明确标定过程。** 保存模型版本、目标函数、权重、参数约束、初值、优化算法、容差、收敛状态及全部模型/参数选择步骤。说明是在原浓度尺度还是对数尺度拟合，两者误差假设不同。后续按原尺度复核 (\mathrm{RMSE}=\sqrt{\frac18\sum_{i=1}^8(y_i-\hat y_i)^2})，列出逐点预测与残差；不要与残差标准差的自由度修正混用。
3. **检查可识别性与误差。** 根据实际采样时间评估灵敏度矩阵的秩、病态程度及参数相关性，结合剖面目标函数或说明假设的区间估计判断稳定性。利用仪器精度、重复测量和残差随时间/浓度的变化评估误差；若证据不足，保留“无法分解”，不强行给出各来源比例。
4. **验证未来预测。** 优先获取同一目标应用条件下、未参与任何选择的后续观测，预先固定预测时间范围、误差指标和可接受容差。若暂时只有8点，可计划按时间顺序进行滚动验证，并在每个训练窗口内重新标定；小样本结果只作探索，不能替代外部验证，也不任意打乱时间进行拆分。报告预测误差及可支持的预测不确定性，明确外推限制。
5. **开展敏感性与稳健性检查。** 以有依据的参数不确定区间和观测扰动范围为基础，检查预测对参数、初值、权重、时间覆盖及单点影响的变化。解析导数为 (\partial y/\partial a=e^{-bt})、(\partial y/\partial b=-at e^{-bt})；后续需在实际时间范围内评价，当前不能声称已获得敏感性结果。
6. **建立可执行交付包。** 保存数据、拟合/验证/模拟/绘图脚本、完整配置、随机数生成器及种子、软件和依赖版本、文件校验信息及README运行命令。后续实际运行后检查数值输出，再检查图中时间（h）、浓度（mg/L）、图例和模拟标识。枚举可用中文字体，选用支持所需字形者，检查PNG及拟交付的PDF/SVG等导出文件，必要时嵌入字体。复现验收应由干净环境执行记录和结果比对支持。
