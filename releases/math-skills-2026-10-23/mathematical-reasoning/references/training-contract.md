# 证明驱动写作训练契约

这是仅在明确请求时人工启动的可选工作流，不是由单篇论文推出的写作定律。阅读或安装 skill 不自动开始训练、连续选文或版本更新。训练目标是形成清楚、可读的数学表达，不能据此改变原数学内容、假设、结果或证明逻辑；发现错误须独立报告。

## 不可倒置的阶段

1. Understand / Reconstruct mathematics：核对象、研究目标、已有结果、原文贡献、每个主定理的条件与使用点。实际重算关键机制、依赖、合法性与闭合，参考[数学推理主文件](../SKILL.md)。
2. 冻结压缩数学骨架并关闭来源：只含目标、假设、困难、机制、关键引理/估计、消去、bootstrap量、紧性/反证机制和最终闭合。详细计算另存，不保存原句、长证明、修辞和作者章节序列。
3. Write independently：仅依数学定理与骨架，自己决定定义、引理、命题、定理、proof roadmap、公式编号、详略和衔接。此阶段不打开发表版本。
4. Mathematical Audit：在来源仍关闭时审查假设、条件、边界、正则性、指数、算子域、紧性、谱种类、常数依赖、bootstrap、Gronwall、续延和循环。发现错误先改，再审到该目标可关闭。
5. Writing Audit：数学通过后，分别查定理、证明、章节、全文层面的目的、依赖、信息顺序、困难提示、公式解释和冗余。不能以更短或更长自动评分。
6. Compare with publication：此时才打开来源；比较数学结构、证明机制、证明表达、信息顺序、语言功能、阅读体验六维。解释双方优势以及个人风格，不仅做diff，不预定原文/新版胜出。
7. 分类并验证：paper-specific只留论文记录；Level1 Observation、Level2 Candidate暂存；跨独立论文检验后，明确给出Level3的理由才能进入核心writing规则。
8. Update / Blind test：版本化更新并记日志。下一篇用同一数学骨架比较旧skill、新skill、发表版本；旧/新稿由未见该来源的隔离写作上下文完成，遵守相同数学/写作审查顺序。测试通过才提高confidence，失败则修订、降级或拆分。

## 训练范围与语言覆盖

要求整篇时，覆盖引言、已知背景与贡献定位、全部主结果及条件用途、全部核心证明、章节推进和收束；不能把困难主结果删掉后仍称整篇完成。限定单元可以作阶段练习，但其完成不抵消整篇覆盖缺口；阅读完整来源也不等于完成整篇独立重构。无法闭合核心内容时按重大错误/未核原则另选来源，不为篇数强修。

中文与英文分别保留真实写作证据；同轮旧/新稿使用相同语言、数学输入和范围。中文独立稿与英文来源的组织比较不自动认证英语成稿，更不认证英语整篇表现。这些覆盖责任属于所选择的任务契约，不是新获得的L3写作规律。

## 隔离与真实记录

数学阅读不可避免见到证明表达。可以将纯数学骨架提供给未接收原文的新写作上下文；只能称表达隔离，不能声称忘记来源、清空先验知识或独立发现全部数学。

保存输入骨架及版本、首次稿、每轮数学审查与修订、写作审查、来源开放点、六维比较和规则决定。 送审文本也包括派生排版稿：一经交给审查者，不再覆盖；即使只改字体或换行，也另存版本并锁定新的摘要。若审查中发生漂移，记录差异，重新核完整diff和最终哈希后才能进入下一门槛，不能将原数学稿不变误写成所有技术副本从未变化。使用真实时间、文件摘要或版本ID，不追补虚构历史。先导试验若缺严格顺序或没有旧/新双轨，注明限制；已看来源的同一上下文不能再次当该篇盲写者。

随首次封存记录实际读取的skill主文件与引用文件清单、版本或散列；区分允许读取、要求读取和已有证据实际读取。版本标签不证明可选候选卡已载入，不追补旧轮读取记录，也不推断隐藏行为。这是实验追溯约束，不是文献归纳的数学规则。

测试任务只给原始材料与对应版本，不泄露预期答案、疑点诊断或新版预期优势。除skill版本外，数学输入、目标语言、范围和评价标准相同。必要更正数学骨架时两组共同更新并记录，不只给新版补答案。审查可盲化稿件标签，先评数学，再评写作；出版版本最后进入比较。

## 证据分级和规则卡

- Level 1 Observation：单篇发现，或多份材料实际依赖同一来源、同一作者模型/同一已泄露任务，不能伪装成独立多证据。
- Level 2 Candidate：至少两篇相互独立论文支持类似规律；说明独立性、共同机制与例外。
- Level 3 Validated：在多论文且数学合理的基础上，明确满足至少一项：多篇不同作者支持；在不同问题有效；独立写作测试显示清晰度提升；有具体可核的组织优势因果解释。只有此层写作规则进核心；下一篇盲测结果才进一步提高confidence。

每条规则记录稳定ID、状态与版本，以及：Rule / Reason / Use when / Avoid when / Good pattern / Bad pattern / Evidence / Confidence。Evidence包含论文版本、实际页段、训练范围、验证任务及未核界限。Confidence与证据等级不混写为“已发表所以strong”。

拒绝课题特有能量/变量/消去上升为通则、同义词改写、个人文风当规范、只看英语句式、为简洁删关键步、为详细无差别扩写。坏例子也须有适用条件与因果说明，不只评价某作者写得差。

## 每篇固定七项报告

1. Mathematical Architecture：目标主定理、策略、困难、决定估计、依赖与假设使用点。
2. Independent Reconstruction Review：数学正确/修正/未闭合与写作冗余/解释/结构分开；给真实审查先后。
3. Published-Version Comparison：六维比较，原文更好、独立稿更好或等效、个人风格无需模仿分别列出。
4. Candidate Writing Rules：带证据与适用/不适用范围的写作候选。
5. Candidate Mathematical Rules：带证据与边界的数学机制候选。
6. Rejected Lessons：不应迁移的表面差异、可疑数学或过拟合及理由。
7. Skill Update Decision：逐条 no update / observation only / candidate / validated / revise existing rule / delete-or-merge obsolete rule。给版本与日志记录，不把待写决定写成已提交。

固定的是报告，不是论文目录或篇幅。

## 重大错误和持续训练

疑似核心重大错误先留证并尽可能独立核验，暂停作为数学范本；正确性评价与可读性观察分开。影响核心结果时可暂时跳过，不能为训练数量强行补新假设或寻找解释。

仅在请求范围明确包括后续训练时，完成一篇后继续相关高质量语料；否则完成本次范围即停止。后续选文优先同问题不同作者、同方法不同方程、同作者不同时期、同类主定理不同路线、经典与现代对照。以现有主线质量优先，不盲目增加数量。冲突时检查适用条件、例外、过度泛化及旧规则是否应拆分、降级或删除合并。

## 日志

在执行者自行管理的训练记录中，真实记录日期、版本前后、规则ID、动作、新增/变更、原因、证据论文、置信等级、废弃/合并及验证结果。保留真实版本历史；未发生的 blind test、技能保存或论文完成不能补造。

公开分享规则时，可将未公开训练记录摘要为来源明确的适用范围与局限；不要公开私人对话、审查路径、稿件别名或其他私密资料。摘要不等于完整证据公开，也不构成可复现 benchmark。
