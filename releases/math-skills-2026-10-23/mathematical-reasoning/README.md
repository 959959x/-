# mathematical-reasoning · 数学证明推理

## 中文

- 版本：R37，源规则版本 v37（2026-10-14）；公开整理日期 2026-10-23。未包含 R38 或未定稿候选版本。
- 用途：重建和审查数学、PDE、泛函分析及谱理论证明，明确假设、估计、算子域、极限与闭合责任。为清楚可读的 AI 数学写作提供审查边界，不认证证明正确，不静默改动数学内容、假设、结论或证明逻辑。
- 使用：从 [SKILL.md](SKILL.md) 开始，按实际问题选择 [审查范围](references/audit-domains.md)。写作表达由相邻的 [mathematical-writing](../mathematical-writing/SKILL.md) 处理。
- 规则：5 张范围受限的已验证检查卡见 [validated-rules.md](references/validated-rules.md)；2 张仍为 Level 2 的机制候选见 [rule-candidates.md](references/rule-candidates.md)。候选不是核心规则，validated 也不是通用定理、准确率保证或免除重算的许可。
- 训练：只在明确请求时采用 [人工启动训练契约](references/training-contract.md)。读取、安装或使用本技能不自动运行训练或持续选文。
- 证据边界：Evidence 仅摘要源 skill 所报告的核验范围。支持性稿件、完整推导和审查记录未公开；本次导出未重新核验论文。不是可公开复现的 benchmark，也没有新增因果性能、阅读效果或普遍适用性结论。原文页码及缩写按源记录保留，不能替代取得实际来源和独立核对。
- 共享来源书目：见写作 skill 的[选定公共书目](../mathematical-writing/references/bibliography.md)，仅帮助识别双方共有的来源，不代表完整训练语料或新增核验。未解开的缩写仍是源记录缩写。
- 许可证：[MIT](../LICENSE)，适用范围见 [LICENSE_SCOPE.md](../LICENSE_SCOPE.md)。未包含宿主配置或图标资产。

## English

This is the portable public documentation export of mathematical-reasoning R37 (source v37, dated 2026-10-14; export 2026-10-23), not R38.

Start with [SKILL.md](SKILL.md). Use the audit domains and scoped rule cards for the actual mathematical task. The companion [mathematical-writing](../mathematical-writing/SKILL.md) handles exposition. The goal is readable AI-written mathematics without silently changing mathematical content, assumptions, results, or proof logic. This skill supports review boundaries; it does not certify proofs.

The five validated cards remain scope-limited, and the two Level 2 mechanism candidates remain non-core. Evidence sections summarize validation reported by the source skill. Supporting drafts, calculations, and audit records are non-public; this export has not reverified the papers and is not a publicly reproducible benchmark. No new confidence, causal performance, adoption, or universal applicability claim is made.

Training is optional and starts only when explicitly requested. Reading or installing these documents does not execute training. See the [manual training contract](references/training-contract.md). Host-specific configuration and icon assets are excluded. See the root [MIT license](../LICENSE) and [license scope](../LICENSE_SCOPE.md).
