## 目标与定位

目标是让AI辅助撰写的数学更易于数学工作者及其他目标读者阅读，同时**不改变已给数学内容、假设、结论和证明逻辑**。这是项目目标，不是阅读效果保证，也不是证明正确性认证。需要数学审查时应另行明确范围，并保留未核与未闭合之处。

本合集为2026-10-23整理的可移植说明文件，不是模型权重、应用程序、自动训练任务或论文语料库。

- [数学论文写作 W35](mathematical-writing/README.md)：原语言润色、明确翻译、按数学依赖和读者需要组织正文；不暗改数学。
- [数学证明推理 R37](mathematical-reasoning/README.md)：按明确请求重建或审查论证，区分已核、条件性与未闭合步骤。
- [数学论文总工作流](math-paper-workflow/README.md)：未编号版本快照，最近源文件更新于2026-10-04；识别研究、审查、组织、润色、学习和建模模式。

不含W36或R38；没有借此次公开整理升级规则、证据等级或置信度。仓库中的旧发布目录保持独立。

## 怎么用

1. 保留三个技能文件夹及许可证，先读取适合本次任务的SKILL.md，再按需读取它链接的参考文件。支持技能导入的助手按其自身说明加载；本合集不自动安装，也不保证所有客户端兼容。
2. 提供真实文稿、目标读者、输出语言、数学基线及允许改动范围。只润色一个段落时，不强制扩大成整篇核验、翻译或训练。
3. 涉及推导或正确性时使用推理说明；只组织已给内容时使用写作说明；跨模式任务从总工作流进入。
4. 要求如实区分技术/编译检查、全文编辑检查、数学保持检查与完整数学审查。排版、编译与逐页查看依赖所用环境的工具，无法完成的检查不能记为通过。

仅复制、阅读或启用这些文件，不授权持续训练、更新规则、上传或其他外部操作。论文学习训练须明确请求并限定范围，按“数学理解与重建 → 关闭来源后独立成稿 → 数学审查 → 写作审查 → 来源比较”的顺序执行。发现数学问题应说明，而非悄悄改成更强假设或另一结论。

示例：请使用数学论文写作说明润色以下中文段落，保持公式、假设、量词、结论和证明逻辑不变；数学疑点另列，不补造证明。

示例：请审查这一证明单元，明确关键估计的条件和闭合位置，分别列出已核步骤与缺口；不要新增假设或将修复后的命题冒充原命题。

示例只说明用法，不是效果实验报告。
