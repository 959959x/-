# 数学论文写作

## 先按任务分流

- 纯润色：在原语言内改善表达并检查数学保持。没有完整证明不阻止润色一个已给定理；不得自动扩成证明核验、训练、翻译或新推导。实质数学疑点另列，只有影响所需改写且无法从上下文判断时才询问。
- 显式翻译：仅执行所需语言转换与数学保持，不自动启动整篇训练。
- 原创正文或结构编辑：使用已有且足够的数学基线；确有推导/正确性任务时才进入数学推理审查，并以其结果为输入。若已安装 $mathematical-reasoning，可调用它；否则按本包训练契约的数学审查范围独立检查，或使用已完成的人工审查。不要求另一个技能才能润色，也不把未完成的数学审查写成通过。
- 论文学习训练：执行下文严格阶段门槛及七项输出。只有这一模式要求完整骨架、双审查与来源比较。

## 固定数学基线与语言

- 在当前任务范围内确认对象、结论、假设和未核状态；写作不能暗改数学强度，流畅不能替代正确。
- 中文原创直接按中文数学论证组织；英文原创直接按英文数学论文组织。润色在原语言内进行；只有明确要求才翻译。读 [语言路线](references/language-routes.md)。
- 不新增研究结果、虚构贡献、文献空白或作者观点。学习性重构须准确归属原作者并声明范围。

## 独立成稿

本节用于原创成稿与训练，不用于把纯润色扩成重写。仅依据冻结的数学定理与压缩骨架决定定义位置、引理是否独立、陈述与证明的位置、关键公式编号、计算详略和衔接。不得重新打开来源；不猜作者原来的目录。

让已有证明机制决定论文结构。结果之间若有推进关系而陈述本身不能显示，应解释其用途。短证明不强加roadmap；长证明是否分段、工具集中还是就地引入，须给数学和读者依赖的理由。不规定固定章节数、篇幅或“一个结果必须一个定理”。

这些是写作操作约定，不等于已验证每一种安排。多阶段重构时先读[范围受限的已验证规则](references/validated-rules.md)，按Use when/Avoid when选择，不固化目录；[候选写作规则](references/rule-candidates.md)不作强制模板，paper-specific内容留在论文报告。公开证据摘要的范围与限制见 [证据说明](references/evidence-notes.md)。

## 顺序不可倒置

在论文训练模式严格执行 [训练契约](references/training-contract.md)：

Understand → Reconstruct mathematics → 压缩骨架并关闭来源 → 独立写作 → Mathematical Audit并修正 → Writing Audit → 打开发表版本作六维比较 → 解释差异 → 候选分级 → 跨论文验证 → 更新skill → 下一篇旧/新/出版版本盲测。

- 只允许在Mathematical Audit解决当前目标的阻塞问题后进入Writing Audit。
- 数学审查与写作审查分别留记录；对照不得只有文字diff，也不能用出版版本替自己的错误找借口。Writing Audit若发现数学断言有误，暂停来源比较，最小修订并重回数学复核，再完成写作审查；真实保存发现者和顺序，不追认早先已经发现。
- 真实披露隔离条件：阅读数学时会看见证明表达；可把纯数学骨架交给未见原文的新上下文，但不能声称忘记了原文或排除了所有先验接触。
- 已经提前接触来源或未留审查顺序证据的稿，只记先导/受限试验，不追认严格盲测。

## Writing Audit

在已正确数学上检查四层：

1. 定理：读者是否知道其需要、假设是否无谓重复、结论责任是否清楚、是否不必要拆分。
2. 证明：整体策略是否需要解释；困难是否突出；关键估计是否被普通计算淹没；解释是否出现在最需要的位置。
3. 章节：预备工具是否实际使用、定义是否过早且长期闲置、转入下一节的原因是否明确。
4. 全文：问题、困难、工具、核心论证、结果与应用是否形成真实依赖。此链是检查关系，不是目录模板。

不得为简洁删必要步骤，也不得为详细机械扩写标准步骤。比较原稿能简洁的数学原因、独立稿真正更清楚之处和纯个人风格；不一概预定新版更好。

## 规则与日志

只有Level 3的已验证写作规律进入核心规则库；Level 1/2分别是Observation/Candidate。每条正式规则使用Rule、Reason、Use when、Avoid when、Good pattern、Bad pattern、Evidence、Confidence，并带稳定ID、证据层级、版本、失效/例外范围。

在用户要求更新规则时维护独立更新日志文件，记录新增、修改原因、证据论文、置信等级、废弃/合并项与可追溯版本；没有发生的操作不能补造。新论文与旧规则冲突时，检查适用条件、过度泛化和是否需要拆分、降级或删除合并，保留既有成果及历史证据。

当前MW-O001/MW-O002/MW-O003继承W35的范围受限L3 validated标签，非strong；KM86-W03仍为L2候选。公开包不包含原始训练材料或逐轮审查记录，不能凭这些历史标签声称独立复现、模型可靠性保证或新版整体胜出。旧经验的证据分类见 [旧规则盘点](references/legacy-evidence-inventory.md)。

## 输出与交付

每篇完成训练后提供契约的七项报告。独立稿、审查和比较报告分开；实际文件遵循文档/LaTeX/PDF技术与逐页渲染验收。固定报告字段不是论文模板。持续训练只在用户明确要求的范围内继续相关语料；遇重大数学问题可留证暂跳，不把数量当训练质量。
